# Arrazola CFDI para Windows

Organiza los XML de cada contribuyente, localiza sus acuses por periodo, coteja facturas PPD con sus complementos de pago y prepara informes en Excel y PDF.

**Prueba de 15 días** para Windows 10 y 11 de 64 bits (Intel o AMD).

- [Ver la versión más reciente y descargar el instalador](https://github.com/arrazola-consultores/arrazola-cfdi-descargas/releases/latest)
- [Consultar el manual de uso en PDF](https://github.com/arrazola-consultores/arrazola-cfdi-descargas/releases/latest/download/Manual_Arrazola_CFDI.pdf)

## Instalar

1. Abre la versión más reciente. En **Assets**, descarga el instalador de Arrazola CFDI, el archivo que termina en `.exe`.
2. Abre el instalador, lee las condiciones y selecciona **Instalar / actualizar para mi usuario**.
3. Abre **Arrazola CFDI - Prueba** desde el Escritorio. Los 15 días comienzan al instalar por primera vez.

Para empezar, registra un contribuyente e importa algunos XML de un mes que ya conozcas. Consulta el tablero de acuses, revisa las facturas PPD y prepara el informe de ese periodo.

## Manual y actualizaciones

- Desde el menú **Arrazola → Manual actualizado** puedes volver a consultar la guía.
- Al iniciar el programa con internet, Arrazola revisa si hay una versión más reciente. También puedes consultarla en **Arrazola → Buscar actualizaciones**. El aviso muestra las novedades y tú decides cuándo descargar y abrir el instalador.
- Antes de actualizar, guarda un respaldo y termina los trabajos en curso. La actualización conserva tus datos y el vencimiento original de la prueba.

El archivo `arrazola-cfdi-prueba.json` de cada publicación permite que Arrazola identifique y verifique la actualización.
